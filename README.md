# MGD Skid Loader Services Static Site v3

Production domain: https://mgdskidloader.com/

This build is plain HTML/CSS/JS and is suitable for GitHub Pages testing and IONOS static hosting. Internal asset and navigation paths are relative so CSS/images work when the site is tested from a GitHub repository path. Canonical URLs remain pointed at the production domain.

Included: seven service pages, service-area page, reviews page, contact/CRM embed, Facebook links, privacy policy, terms and conditions, robots.txt, llms.txt, sitemap.xml, 404 page, project images and MP4 video.

Before replacing the WordPress site, inventory all live WordPress URLs and create 301 redirects for any URLs that will change.
